# 棒球比赛助手电脑版

一款离线运行的 Windows 棒球比赛记录与直播比分牌软件，优先适配 OBS、抖音直播伴侣和视频号直播工具。

## 运行

- 安装版：运行 `release/BaseballAssistant-Setup-0.1.0-x64.exe`。
- 便携版：运行 `release/BaseballAssistant-Portable-0.1.0-x64.exe`。
- 开发模式：执行 `npm install` 后运行 `npm start`。

支持 Windows 10/11 64 位。比赛数据保存在 Windows 当前用户的应用数据目录中，可在软件内点击“打开数据目录”查看，也可以导出 JSON 备份。

## 直播采集

1. 在操作台点击“打开比分牌窗口”。
2. 在 OBS、抖音直播伴侣或视频号直播工具中添加“窗口采集”，选择“棒球比分牌输出”。
3. 默认使用绿幕背景；添加色度键并选择绿色即可。若直播软件能够保留窗口透明度，也可在操作台切换为“透明”。
4. 关闭“鼠标穿透”后，按住比分牌顶部赛事标题栏可以拖动窗口；也可以在直播软件中缩放和定位采集源。
5. 若开启鼠标穿透，可在操作台关闭；点击“定位窗口”也会临时关闭穿透并聚焦比分牌。

## 核心操作

- `B` 坏球、`S` 好球、`F` 界外球、`O` 出局。
- 第四个坏球、第三个好球和第三个出局均会要求确认。
- 三出局后自动清空 BSO 与垒包并切换半局。
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。
- 暂停直播同步后，可先在操作台修正数据，再一次发布到直播画面。
- 安打进垒采用建议结果，确认后仍可直接修正比分和垒包。

## 数据与限制

- 第一版只记录比赛数据，不包含球员名单及个人技术统计。
- 计划局数只作提示，实际比赛可以提前结束或进入任意延长局。
- 当前提供一套深色职业转播风格，主题系统将在后续版本扩展。
